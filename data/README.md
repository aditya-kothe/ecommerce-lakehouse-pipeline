
# Data Directory

This directory is reserved for local source datasets and temporary
development data.

Raw and processed datasets are excluded from Git tracking by default.

The primary source dataset is the public Olist Brazilian E-Commerce
dataset.

Dataset page:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Dataset download instructions, attribution, license details, and
source file descriptions will be documented before ingestion begins.
